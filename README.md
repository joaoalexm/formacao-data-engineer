# Data Engineering Training

This repository documents my practical training journey in Data Engineering.

The goal is to build the skills required for a Junior Data Engineer role through hands-on exercises, projects, testing, documentation, and development practices commonly used in real-world environments.

## Training Structure

### Phase 1

* Git and GitHub
* Python
* SQL Server / T-SQL

### Phase 2

* Apache Spark / PySpark
* Azure Databricks

### Final Project

An end-to-end Data Engineering project covering data ingestion, transformation, quality, storage, processing, and consumption.

## Learning Approach

The training follows a simple workflow:

**Learn → Build → Test → Document → Review → Improve**

Exercises and projects will be developed using issues, branches, commits, and pull requests to document both the technical work and my progress over time.
