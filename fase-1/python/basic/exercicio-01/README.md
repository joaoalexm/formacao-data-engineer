# Python 01 — Student Profile

## Goal

Display a student profile using variables, user input, type conversion, `print`, and f-strings.

## Input

The program asks the user for:

- name
- age
- course
- semester

Age and semester are converted to integers.

## Example

Input:

```text
joao
20
it
4
```

Output:

```text
===Student Profile===
Hello, joao!
You are 20 years old,
studying it
in semester 4.
```

## How to run

```bash
python main.py
```

## What I learned

I practiced reading user input, converting numeric values with `int()`, storing values in variables, and formatting output with f-strings.
