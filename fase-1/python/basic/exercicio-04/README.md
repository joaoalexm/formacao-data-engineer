# Python 04 - Number Classifier

## Goal

Classify an integer by sign, parity, and primality.

## Input

The program asks the user for an integer.

The input must be a valid whole number.

## Classification

The program identifies whether the number is:

- positive, negative, or zero
- even or odd
- prime or not prime

Numbers lower than 2 are treated as not prime.

## Example

    Digit a number: 7
    The number is positive.
    The number is odd.
    The number is prime.

## How to run

    python main.py

## What I learned

I practiced validating integer input with try/except, using the modulo operator to classify even and odd numbers, iterating with for and range, using break inside loops, and checking whether a number is prime.
