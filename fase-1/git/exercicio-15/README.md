# Git 15 - History and Audit

## Goal

Practice inspecting repository history and finding when and why changes were made.

## Commands

git log --oneline
git log --grep="<text>"
git show <commit>
git log -- <file>
git blame <file>

## What I learned

I learned how to inspect commit history, search for specific changes, see what a commit changed, and identify which commit modified a line in a file.
